## 出力

`{{schema}}` に従った JSON だけを返してください。
前置き・後書き・コード柵は付けないでください。

- 候補は最大 3 件、確信度の高い順
- 候補が立たない場合は `candidates` を空の配列にしてください（無理に挙げない）
- 合わない点は `mismatches` に、確認できなかった点は `unverified_points` に書いてください
- 日本語で書いてください（`title_original` と `sources` の URL を除く）
