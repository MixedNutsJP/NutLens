# 作品の特定

`CLAUDE.md` の「守ること」が優先する。特に**顔から人物を特定しない**。

---

## 手順 1. 全フレームを読む

`frames/` のフレームを**すべて** Read で読む。飛ばさない。
ファイル名の `t0012.3s` は撮影開始からの経過秒で、動画の再生位置ではない。

1 枚ごとに、次を書き出す（頭の中ではなく、作業として列挙する）。

| 見るもの | 例 |
|---|---|
| 場面 | 屋内／屋外、昼夜、天候、人数 |
| 舞台・土地 | 建物の様式、看板の言語、車のナンバー、植生 |
| 時代 | 服装、電話・PC の有無、車種、画面の質感 |
| 言語 | 看板・字幕・テロップの言語 |
| テロップ・ロゴ | 配信元のロゴ、チャンネル名、題名らしき文字列 |
| 特徴的な小道具 | 武器、道具、乗り物、動物、特殊な装置 |
| 表現 | 実写／アニメ／CG、画角、色調 |

ショート動画はループ再生されるので、**同じ場面が時刻違いで複数回現れることがある**。
同じ場面は 1 つとして数える。

**フレームが真っ黒・ほぼ単色ばかりのときは、そう書く。**
画面の保護（HDCP）で映像が取れていない可能性があり、
無理に推測するより「取れていない」と報告するほうが役に立つ。
その場合は `candidates` を空にし、`unverified_points` にその旨を書く。

## 手順 2. 文字起こしと OCR から抜き出す

`transcript.txt` と `ocr.txt` があれば読む（無ければ飛ばす）。

抜き出すもの:

- **固有名詞**：人名・地名・組織名・作品名らしき語
- **あらすじのキーワード**：誰が、どこで、何をして、どうなるか
- **数字**：公開年、賞の名前、順位

文字起こしは誤変換を含む。**音が近い別の語の可能性も控えておく**
（例：「インサイド」←→「インサイダー」）。

## 手順 3. Web で検索する（英語と日本語の両方）

手順 2 のあらすじのキーワードで検索する。

- **英語と日本語の両方で検索する。** 片方だけだと、海外の短編や日本未公開作品に届かない
- あらすじで引く。例：`art thief trapped penthouse movie` / `ペントハウス 閉じ込められる 窃盗犯 映画`
- 題名らしき文字列がテロップにあるなら、それも引く
- **俳優名で引かない**（`CLAUDE.md` の守ること 1）

使った検索語は `search_queries_used` にそのまま入れる。

有望なページは WebFetch で開いて中身を確かめる。
**検索結果の要約だけで判断しない。**

## 手順 4. 候補ごとに照合する

候補 1 件ごとに、手順 1 で書き出した特徴と、あらすじ・公開年・舞台を突き合わせる。

- 合った特徴 → `evidence`
- **合わなかった特徴 → `mismatches`**
- 確かめられなかった点 → `unverified_points`

## 手順 5. 合わない点はそのまま残し、確信度を下げる

`mismatches` を空にするために無視したり、言い換えたりしない。
合わない点が 1 つでもあれば `confidence` を下げる。

## 手順 6. 出力する

- 候補は**最大 3 件**。`confidence` の高い順に並べる
- 候補が立たなければ `candidates` は空の配列
- `schema/result.schema.json` に従った JSON **だけ**を返す。前置きも後書きも付けない
- 日本語で書く（`title_original` と `sources` の URL を除く）
