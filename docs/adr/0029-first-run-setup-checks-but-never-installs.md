# ADR-0029. 初回セットアップは確認と案内に徹し、Claude Code の導入を自動化しない

- 状態: **採用**（2026-11-14 承認）
- 日付: 2026-11-14

## 背景

D-03「初回起動時にセットアップ画面を出す。(1) `claude` コマンドがあるか、
(2) **ログイン済みで `claude -p` が動くか**、(3) Whisper モデルがあるか を確認し、
足りないものは公式の導入手順へのリンクとともに案内する。
**Claude Code の導入そのものは自動化しない**」

D-07「解析には利用者自身の Claude の利用枠を使うこと、画像・音声の文字起こしが
Claude に送られることを、**初回セットアップと README に明記する**」

「自動化しない」は要件で決まっている。決めるのは次の 3 つ。

1. (2) の「`claude -p` が動くか」を**どうやって**確かめるか
2. 足りないときに起動を止めるか
3. この画面をいつ出すか（初回だけか、足りないときは毎回か）

**1 が効いてくる。`claude -p` を実行することは、利用者の利用枠を使うことである。**
起動のたびに黙って走らせると、**押していないのに利用枠が減る。**

## 決定

### 1. 3 つの確認を、段を分けて行う

| 確認 | やり方 | 利用枠を使うか |
|---|---|---|
| (1) `claude` があるか | 既存の `IClaudeCliLocator` で探し、`claude --version` を実行する | **使わない** |
| (2) `claude -p` が動くか | **利用者が「確認する」を押したときだけ**、ごく短いプロンプトを 1 回投げる | **使う**（だから押させる） |
| (3) Whisper のモデルがあるか | ファイルの有無を見るだけ | 使わない |

**(2) を自動で走らせない。** ボタンに「（利用枠を少し使います）」と添える。

**押していないのに利用枠が減る**のは、このアプリが最も避けるべきことの一つ。
解析そのものが利用者の利用枠で動くので（D-07）、枠は利用者の資源として扱う。

### 2. 足りなくても起動は止めない

| 足りないもの | 影響 |
|---|---|
| `claude` が無い | **撮影はできる。** 解析のときに案内を出す |
| ログインしていない | 同上 |
| Whisper のモデルが無い | **撮影も解析もできる。** 文字起こしだけ飛ぶ |
| OCR の言語パックが無い | テロップの読み取りだけ飛ぶ |

**補助が揃っていないだけで止めない**（概要設計 §10.1。段階 3 以降ずっと同じ方針）。

### 3. 初回は必ず出す。2 回目以降は「足りないもの」があるときだけ出す

```
初回        → 必ず出す（D-07 の説明があるため）
2 回目以降  → (1) か (3) が欠けていれば出す。揃っていれば出さない
いつでも    → 設定画面から開ける
```

**揃っているのに毎回出さない。** 読まれなくなる。

「出した」ことは `settings.json` に覚える（`setup.completedVersion`）。
**説明の内容を変えたら版を上げ、もう一度出す**（ADR-0021 の同意と同じ考え方）。

### 4. D-07 の説明をこの画面に載せる

```
NutLens は、撮影した画面と音を、利用者ご自身の Claude Code に渡して調べます。

・解析には、ご自身の Claude の利用枠を使います。
・フレーム画像・音声の文字起こし・OCR の結果・入力したメモが Claude Code に渡ります。
・Claude Code は会話履歴をこの PC に保存します。読み取らせた画像も残ります。
・Web Detection（既定オフ）を有効にした場合は、選んだフレームが Google にも送られます。
・アプリ独自の送信はありません。
```

**この画面を閉じないと撮影に進めない**のは初回だけ。読ませるためではなく、
**一度は目に入るようにする**ため。

### 5. 導入の案内は公式の手順へのリンクだけにする

インストールのコマンドを画面に出して実行させない。
**公式の手順に送る。** 導入の方法は変わるが、公式のページは追従する。

| 足りないもの | 案内先 |
|---|---|
| Claude Code | 公式のインストール手順 |
| Whisper のモデル | **アプリ内でダウンロードできる**（ADR-0030） |
| 日本語 OCR | Windows の「言語と地域」の設定を開く |

## 影響

- `SetupViewModel` / `SetupWindow`（App）
- `SetupSettings` が増える：`CompletedVersion`（既定 0）
- `IClaudeCliLocator` はそのまま使える（段階 2 で作った）
- (2) の実行には `IAnalysisEngine` を使わず、専用の短い呼び出しを足す
  （解析の経路に「お試し」を混ぜない）

## 実装で分かったこと（2026-11-14）

### 1. **×で閉じると「使いはじめる」と同じ扱いになっていた**（直した）

利用者からの指摘。

> セットアップ途中でバツ閉じした場合でもインストールが終わっています。中止可能にしてください

決定 4 で「この画面を閉じないと撮影に進めないのは初回だけ」と書いたが、
**閉じ方を 1 つしか考えていなかった。**
「使いはじめる」を押しても ×で閉じても同じ経路を通り、
**説明を読まずに素通りできる状態だった。** D-07 が実質効いていない。

直した内容:

| 閉じ方 | 初回 | 2 回目以降 |
|---|---|---|
| 「使いはじめる」 | 進む。説明を見たことを記録する | 進む |
| **「中止する」** | 確認のうえ**アプリを終了** | そのまま使える |
| **×・Esc** | 同上 | 同上 |

**確認は 1 箇所（`OnClosing`）に集める。** ×・中止ボタン・Esc のどれを通っても同じ確認が出る。
別々に書くと、どれか 1 つだけ確認が漏れる。

**「中止する」ボタンも置いた**（利用者からの追加の指摘）。
×だけだと、中止できることが画面から分からない。

### 2. モデルを落としている途中なら、確認の文面を変えて止める

落としている最中に中止すると、ダウンロードも止める。
**途中のファイルは残す**ので、次回は続きから再開する（ADR-0030 決定 3）。
そのことを確認の文面に書く。

### 3. 画面の印は絵文字にした

利用者からの指摘。

> 一瞬ラジオボックスに見えるので変更してください

`○` / `―` を使っていた。**ラジオボタンに見え、押して入力するものだと誤解される。**
✅（使える）/ ⚠️（使えない）/ ❓（まだ確かめていない）の 3 つにした。

同時に `SetupCheck` を 2 状態（bool）から 3 状態にした。
**`claude -p` は押すまで確かめない**ので、
2 状態のままだと「押していないだけ」が「使えない」として出る。

状態と重複する文言（「あります」「動きました」「使えます」）も落とした。
**印が状態を示すので、同じことを二度言わない。**
添えるのは場所・版・大きさなど、読む価値のある情報だけにした。

## 宿題

- **(2) の「ごく短いプロンプト」が何を投げるべきか決めていない。**
  利用枠の消費を最小にしつつ、ログイン済みかどうかが分かるもの。実測して決める
- 画面は**未作成・未目視**
- Windows の「言語と地域」を開くための URI（`ms-settings:regionlanguage`）が
  この環境で効くか（未検証）

## 却下した案

| 案 | 却下の理由 |
|---|---|
| 起動のたびに `claude -p` を自動で走らせて確認する | **押していないのに利用者の利用枠が減る。** 起動が遅くなるうえ、オフラインでは毎回失敗する（決定 1） |
| `claude --version` だけで「動く」と判定する | ログインしていない場合を見逃す。**D-03 は「ログイン済みで `claude -p` が動くか」と明示している** |
| Claude Code のインストールを自動化する | **D-03 が明示的に禁止している。** 他人の配布物を勝手に入れることにもなる |
| インストールのコマンドを画面に出して実行させる | 導入の方法は変わる。**画面に焼き付けた手順は古くなり、古い手順のまま案内し続ける**（決定 5） |
| 足りないものがあれば起動を止める | 撮影はできる。**補助が揃っていないだけで止めない**（決定 2） |
| セットアップ画面を初回しか出さない | モデルを消した・Claude Code を消した場合に、何が足りないか分からなくなる（決定 3） |
| 揃っていても毎回出す | 読まれなくなる。閉じる操作が増えるだけ（決定 3） |
| D-07 の説明を README だけに書く | **D-07 が「初回セットアップと README に」と両方を指定している** |
