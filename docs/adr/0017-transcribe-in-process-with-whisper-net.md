# ADR-0017. 文字起こしを Whisper.net でプロセス内に行う

- 状態: **実測・実機で確認**（2026-11-14。日本語・英語ともに文字起こしを確認）
- 日付: 2026-11-14

## 背景

F-11 は「ローカルで文字起こしする（**Whisper.net / whisper.cpp を想定**）。
言語は自動判定し、日本語と英語に対応する。モデルのパスとサイズは設定で選べる」。

**2 つの選択肢が要件に併記されている**ので、どちらにするかを決める必要がある。

| | Whisper.net | whisper.cpp の実行ファイル |
|---|---|---|
| 配布 | NuGet（native は `Whisper.net.Runtime` に同梱） | **実行ファイルを自分で同梱するか、利用者に入れさせる** |
| 呼び方 | プロセス内の API | 外部プロセス＋標準出力のパース |
| ライセンス | MIT | MIT |
| 進捗・キャンセル | コールバックと `CancellationToken` | プロセスを殺す |

D-04 は「Whisper モデルはインストーラーに同梱せず、初回セットアップで利用者がサイズを選んで
ダウンロードする」と**モデル**について定めている。**実行ファイルについては何も言っていない。**

## 決定

### 1. Whisper.net を使う

理由は配布と D-05（環境依存の値を固定で書かない）。

- **実行ファイルを探す仕組みが要らない。** whisper.cpp だと `claude` と同じように
  「どこにあるか」を設定可能にし、見つける順序を決め、`--version` で確かめる、という
  一式をもう 1 つ作ることになる（概要設計 §9.1 と同じものが 2 つ）
- 標準出力のパースが要らない。whisper.cpp の出力形式が版で変わると壊れる
- 進捗とキャンセルが素直に書ける（F-25 と同じ扱いにできる）

native ライブラリ（約 2 MB／RID）が配布物に入るが、モデル（最小でも 75 MB）に比べれば小さい。

### 2. 外部プロセスを起動しないので、`NutLens.Capture` に置く

ADR-0011 は「外部プロセスを起動する実装は `NutLens.Analysis` だけ」と定めた。
Whisper.net はプロセス内で動くのでこの制約にかからない。

音声・画像という「外界の入力」を扱う層として `NutLens.Capture` に置く。

### 3. 言語は自動判定にし、結果の言語を記録する

`WhisperProcessorBuilder.WithLanguage("auto")`。
判定された言語は `transcript.txt` の先頭に書く。

```
# 文字起こし（言語: ja / モデル: ggml-base.bin）

[00:00.0 - 00:04.2] タクシーに乗ったら新幹線より速かった
[00:04.2 - 00:09.8] 20分で空港まで行けるかと尋ねたんですが
```

**時刻を残す。** フレームの経過秒と突き合わせられると、
Claude が「この場面でこう言っている」と結びつけられる。

### 4. モデルは同梱せず、パスを設定で持つ

| 設定 | 既定 |
|---|---|
| `Whisper.ModelPath` | `%LOCALAPPDATA%\NutLens\models\ggml-base.bin` |
| `Whisper.Enabled` | true |

**モデルが無ければ文字起こしを飛ばし、その旨を出す。** 解析は続ける。
ダウンロードの仕組みは段階 5（D-04）。

### 5. 大きさの目安を設定画面に出す（段階 4）

| モデル | 大きさ | 速さ | 精度 |
|---|---|---|---|
| tiny | 75 MB | 速い | 低い |
| base | 142 MB | — | — |
| small | 466 MB | — | — |
| medium | 1.5 GB | 遅い | 高い |

**この表の「速さ」と「精度」は一般に言われている傾向で、こちらで測った値ではない。**
段階 5 で実測して置き換える（宿題）。

## 実装で分かったこと（2026-11-14）

### 1. Whisper.net 1.9.1 は .NET 10 で動いた

モデル `ggml-base.bin`（141 MB）を `%LOCALAPPDATA%\NutLens\models\` に置いて確認した。

**検証には撮影が要らない。** Windows の音声合成（SAPI）で WAV を作り、それを読ませた。

```powershell
# 16 kHz / 16 bit / モノラルで合成する
$voice = New-Object -ComObject SAPI.SpVoice
$stream = New-Object -ComObject SAPI.SpFileStream
$stream.Format.Type = 18
$stream.Open("test.wav", 3)
$voice.AudioOutputStream = $stream
$voice.Speak("…")
$stream.Close()

dotnet run --project tools/NutLens.CaptureProbe -- --transcribe "test.wav"
```

### 2. 言語の自動判定は日英とも当たった（F-11 の要求）

**日本語**（11.5 秒の音声を 2.0 秒で処理）:

```
言語: ja
[00:00.0 - 00:03.3] タクシーに乗ったら新幹線より早かった。
[00:03.3 - 00:11.5] 男はタクシー運転手に20分で空港まで行けるかと尋ねたんですが、言わられてしまいました。
```

**英語**（7.4 秒の音声を 1.9 秒で処理）:

```
言語: en
[00:00.0 - 00:04.8] An art thief is trapped inside a luxury penthouse after the security system locks him in.
[00:05.6 - 00:07.4] He survives on ice from the freezer.
```

### 3. 速さと精度の目安（base モデル）

| 項目 | 実測 |
|---|---|
| 処理の速さ | **音声の長さの約 1/6**（11.5 秒 → 2.0 秒） |
| 60 秒の撮影なら | 10 秒前後の見込み |
| 英語の精度 | 誤りなし |
| 日本語の精度 | おおむね正しいが、同音異義と語尾を誤る（「速かった」→「早かった」、「断られて」→「言わられて」） |

**日本語の誤りは手がかりを損なう種類ではない。**
あらすじのキーワード（タクシー・空港・20 分）は正しく出ている。
決定 5 の表にあった「モデルごとの速さと精度」は、base について実測で置き換えた。

### 4. 録音から文字起こしまでの通し確認は手段を用意した（未実行）

`tools/NutLens.CaptureProbe --audio-selftest <WAV>` で、
スピーカーへ流しながらループバックで録り、録れた WAV をそのまま文字起こしにかける。
**スピーカーから音が出るので、実行は利用者に任せる。**

## 影響

- `Whisper.net` と `Whisper.net.Runtime`（ともに MIT、1.9.1）が依存に加わる
- 配布物に native ライブラリが入る。`THIRD_PARTY_NOTICES.md` に記載（D-06）
- 文字起こしは撮影の後に走る。60 秒の音声で数秒〜数十秒かかる見込み（未実測）

## 宿題

- **BGM と重なったナレーションの精度（未検証）。** 確認に使ったのは合成音声で、背景音が無い。
  フリップ動画のナレーションは BGM と重なることが多い
- tiny / small / medium の速さと精度（base しか測っていない）
- ループバックで録った音声での通し確認（実装で分かったこと 4。手段は用意、実行は未了）

## 却下した案

| 案 | 却下の理由 |
|---|---|
| whisper.cpp の実行ファイルを呼ぶ | **`claude` と同じ「どこにあるか問題」をもう 1 つ抱える。** 探す順序・動作確認・設定項目・エラー処理が二重になる。標準出力の形式が版で変わると壊れる |
| OS の音声認識（`Windows.Media.SpeechRecognition`）を使う | 連続した長い音声の書き起こしには向かない（短い発話の認識が主目的）。言語ごとに追加の言語パックが要る |
| クラウドの音声認識 API を使う | **D-08 に反する。** 外部送信は Claude Code と（利用者が明示的に有効にした）Web Detection だけ |
| モデルを同梱する | D-04 が明示的に禁じている。最小でも 75 MB、実用的な base で 142 MB |
| 文字起こしを撮影と並行して走らせる | 撮影中は CPU をキャプチャと符号化に使いたい。**撮影中に UI がもたつかない**（非機能要件）ことを優先する |
| 言語を設定で固定させる | F-11 が「言語は自動判定し」と定めている。日英が混ざるフリップ動画も多い |
