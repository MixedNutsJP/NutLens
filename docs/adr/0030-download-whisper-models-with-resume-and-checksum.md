# ADR-0030. Whisper のモデルは Hugging Face から再開つきで落とし、ハッシュで照合する

- 状態: **採用**（2026-11-14 承認）。**決定 2 は [ADR-0034](0034-offer-every-multilingual-whisper-model.md) が置き換えた**
- 日付: 2026-11-14

> **注記（2026-11-14）.** 実測の結果、決定 2 の却下理由
> （「`large` は 3 GB 近くあり、短い動画の文字起こしに見合わない」）は
> **`large-v3`（2951 MB）にしか当てはまらなかった。**
> `large-v3-turbo` は 1549 MB で、`medium`（1462 MB）とほぼ同じ。
> **決定 2 は [ADR-0034](0034-offer-every-multilingual-whisper-model.md) に置き換わっている。**
> 決定 1・3・4・5・6 はそのまま効く。

## 背景

D-04「Whisper モデルはインストーラーに同梱せず、初回セットアップで
**利用者がサイズを選んでダウンロードする（進捗表示・中断・再開つき）**」

同梱しないことと、進捗・中断・再開は要件で決まっている。決めるのは次の 4 つ。

1. どこから落とすか
2. どのサイズを選ばせるか
3. 中断と再開をどう実現するか
4. **落ちてきたものが本物かをどう確かめるか**

**4 が要件に書かれていない。** だが、落としてくるのは
**このアプリがプロセス内で読み込んで実行する native のモデル**である（ADR-0017）。
途中で壊れたファイルや、差し替えられたファイルをそのまま読ませない。

## 決定

### 1. 落とし先は Hugging Face の `ggerganov/whisper.cpp`

whisper.cpp 本家が配っている ggml 形式のモデル。**MIT。**
Whisper.net が読むのもこの形式（ADR-0017）。

端点は定数にする。**設定で変えられるようにしない**（ADR-0019 決定 6 と同じ理由：
落とし先を設定ファイルで差し替えられると、「どこから落ちてくるか」が崩れる）。

### 2. 選ばせるのは 4 つだけ

| 名前 | 大きさの目安 | 向き |
|---|---|---|
| `tiny` | 約 75 MB | とにかく軽くしたい |
| `base` | 約 142 MB | **既定。** 段階 3 で日英の自動判定を確認済み |
| `small` | 約 466 MB | 精度を上げたい |
| `medium` | 約 1.5 GB | さらに上げたい。**時間がかかる** |

`large` は入れない。**3 GB 近くあり、短い動画の文字起こしに見合わない。**
手で置けば使える（`whisper.modelPath` で指定できる。D-05）ことは README に書く。

大きさは**目安として画面に出す。** 1.5 GB を知らずに押させない。

### 3. 中断と再開は HTTP の Range で行う

```
models/ggml-base.bin.part   ← 落としている途中。再開はこのファイルの大きさから
models/ggml-base.bin        ← 照合が通ってから、この名前に変える
```

**完成した名前のファイルを、途中の状態で作らない。**
作ると、次の起動で「モデルがある」と判定され、**壊れたモデルを読み込もうとする。**
名前を変えるのは、大きさとハッシュの照合が通った後だけにする。

サーバが Range に対応していなければ、**最初から落とし直す**（黙って失敗しない）。

### 4. 落としたら SHA-256 で照合する

アプリに期待値を持つ。合わなければ `.part` を消して失敗にする。

**途中で壊れたファイルを読ませない**ことが第一の目的。
副次的に、配布元が差し替わった場合の検出にもなる。

**期待値はこちらで実測して埋める。** 公開されている値をそのまま信じて書かない
（書き写しの間違いが「いつまでも落とせない」という形で出る）。

### 5. 失敗しても撮影と解析は続く

モデルが無ければ文字起こしだけ飛ぶ（段階 3 からずっと同じ）。
**ダウンロードの失敗でアプリを止めない。**

### 6. 落とす先は `%LOCALAPPDATA%\NutLens\models\`

既に `IAppDataPaths.ModelsRoot` がある（段階 1 から）。
**アンインストールで消さない**（ADR-0027 決定 3）。入れ直しに時間がかかるため。

## 影響

- `IModelDownloader`（Core 抽象）/ 実装は `NutLens.Analysis`
  （**外へ出る経路はそこだけ**。ADR-0011 / D-08）
- 外部へ出る経路が **3 つめ**になる：Claude Code / Google Vision（任意）/ Hugging Face
  **D-08 の「Claude Code 以外へ送らない」は送信の話で、こちらは受信（ダウンロード）。**
  送るデータは無い。README の「外部に出るもの」の節は送信だけを数える
- 進捗は `IProgress<double>`。中断は `CancellationToken`

## 実装で分かったこと（2026-11-14）

### 1. 大きさを実測した。**決定 2 の「`large` は 3 GB 近い」は、半分しか当たっていなかった**

Hugging Face の `Content-Length` で測った。

| 名前 | 実測 | 決定 2 に書いた目安 |
|---|---|---|
| `tiny` | 74 MB | 75 MB |
| `base` | 141 MB | 142 MB |
| `small` | 465 MB | 466 MB |
| `medium` | **1462 MB** | 1500 MB |
| `large-v3` | **2951 MB** | （3 GB 近い、と書いた） |
| **`large-v3-turbo`** | **1549 MB** | **測っていなかった** |

**`large-v3-turbo` は medium とほぼ同じ大きさである（1549 MB 対 1462 MB）。**

決定 2 は「`large` は 3 GB 近くあり、短い動画の文字起こしに見合わない」として外したが、
その根拠が当てはまるのは `large-v3` だけで、**`large-v3-turbo` には当てはまらない。**
`medium` を選ばせておきながら、ほぼ同じ大きさの `large-v3-turbo` を外す理由が無い。

**決定 2 を見直す必要がある。** 変えるなら新しい番号で起こす（CLAUDE.md §3）。

コードの目安は実測値に差し替えた。**推測で書いた数字を残さない。**

### 2. **実機でダウンロードが通った**（2026-11-14）

利用者が初回セットアップから `large-v3-turbo` を落とした。

```
ggml-large-v3-turbo.bin   1549 MB   2026/11/14 6:04:28
```

**大きさが、こちらで実測した `Content-Length`（1549 MB）と一致している。**
`.part` も残っていないので、決定 3 の「照合が通ってからだけ完成した名前にする」が
通っている。

落ち終わった 6:04:28 の直後、6:04:44 に `settings.json` が書かれており、
`PersistModelPath` の順序とも合う。

**ただし中断と再開（Range）は試していない。** 一度で落ち切っている。

## 宿題

- **SHA-256 の期待値をまだ測っていない。** 4 つぶん実測して埋める
- **中断と再開（`.part` からの続き）は未検証。** 一度で落ち切ったため、途中で切る試行をしていない
- Hugging Face が Range に対応しているか（未検証。対応していなければ決定 3 の退避側が効く）
- `medium` を落とすのにかかる時間（回線による。目安を画面に出すか決めていない）

## 却下した案

| 案 | 却下の理由 |
|---|---|
| インストーラーに同梱する | **D-04 が明示的に禁止している。** `base` でも 142 MB あり、使わない利用者にも配ることになる |
| 落とし先を設定で変えられるようにする | **どこから落ちてくるかが設定ファイルで崩れる。** 手で置いたモデルを使う道（`whisper.modelPath`）は別にある（決定 1） |
| `large` も選べるようにする | 3 GB 近くある。**短い動画の文字起こしに見合わない。** 手で置けば使える（決定 2） |
| 落としている途中から完成した名前で書く | 次の起動で「モデルがある」と判定され、**壊れたモデルを読み込もうとする。** 失敗が「文字起こしが変」という遠い形で表れる（決定 3） |
| ハッシュを確かめない | **プロセス内で読み込んで実行するもの**を、中身を確かめずに読む。途中で切れたファイルも検出できない（決定 4） |
| 期待値を公開値の書き写しで埋める | 書き写しの間違いが「いつまでも落とせない」という形で出る。**自分で測る**（決定 4） |
| ダウンロードに失敗したらアプリを止める | 文字起こしは補助。撮影も解析もできる（決定 5） |
| アンインストールでモデルも消す | 数百 MB〜1.5 GB の入れ直しになる。利用者が自分で消せる場所にある（決定 6） |
