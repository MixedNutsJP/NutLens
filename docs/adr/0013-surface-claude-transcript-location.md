# ADR-0013. Claude Code の会話履歴に画像が残ることを画面で明示する

- 状態: **採用**（2026-11-13、実測にもとづく）
- 日付: 2026-11-13

## 背景

5.5 章は、撮影した画像を「結果画面を閉じたとき／次の撮影を始めたとき／アプリを終了したとき」に
**自動的に完全に消す**と定めている。アプリはそのとおり `frames/` を消す。

だが実測で、**消えないもう 1 つの複製**があることが分かった（ADR-0007 実装で分かったこと 2）。

```
%USERPROFILE%\.claude\projects\<作業ディレクトリのパスを - に置き換えたもの>\<セッションID>.jsonl
```

| もの | サイズ |
|---|---|
| 元の JPEG（626 × 353） | 12 KB |
| **Claude に 1 枚読ませた後の `.jsonl`** | **104 KB** |
| `"data"` の先頭 | `/9j/4AAQSkZJRgABAQEAYABgAAD/2wBD…`（JPEG の base64） |

**読ませた画像は base64 で会話履歴の本文に残る。** フレーム 20 枚なら数 MB 規模になる。

5.5 章は同時にこう定めている。

> Claude Code は自身の会話履歴を利用者の PC に保存する場合がある（保存先と内容は要確認）。
> **アプリからは削除しない**が、その旨を README と初回セットアップに書く

つまり「消すな、ただし伝えろ」。**伝え方を決める必要がある。**
README と初回セットアップ（段階 5）だけでは、
**撮るたびに増えていくことに利用者が気づける場所がない。**

## 決定

### 1. アプリからは消さない

`.claude` 配下には一切触れない。読み取りもしない。

理由：そこは Claude Code が持つデータで、NutLens 以外のセッションも同じフォルダに入る。
アプリが消しにいくと、利用者の別の作業を壊しうる。

### 2. 結果画面に「この解析の会話履歴の場所」を出し、パスをコピーできるようにする

結果画面の下部に、折りたたんだ領域として置く。

```
▸ この解析のデータについて
    撮影した画像は削除しました。
    ただし Claude Code 側の会話履歴には、読み取らせた画像が残っています。
      <.jsonl のフルパス>                                        [パスをコピー] [フォルダを開く]
    消す場合は、上のファイルを削除してください。
```

**画面に出すのは、解析のたびに増えることに気づける場所がそこしかないから。**
初回セットアップは 1 回しか見ない。README は読まれないことがある。

### 3. パスは「組み立てる」のではなく「探す」

エスケープ規則（`:` と `\` を `-` に置き換える）は**観察からの推測**で、
Claude Code の版で変わりうる。規則を信じてパスを組み立てると、
版が変わったときに**存在しないパスを「ここにあります」と表示する**ことになる。

代わりに `%USERPROFILE%\.claude\projects\*\<セッションID>.jsonl` を探す。
セッション ID はこちらが決めているので（ADR-0007）、ファイル名で一意に当たる。
見つからなければ**「見つかりませんでした」と出す。** 推測のパスを出さない。

### 4. 文言は「削除しました」と「残っています」を並べて書く

片方だけ書くと誤解になる。
「画像は削除しました」だけでは残っている複製を隠すことになり、
「履歴に残ります」だけでは一時データの削除が効いていないように読める。

### 5. README と初回セットアップにも同じことを書く（段階 5）

D-07 の要求。画面に出すこととは別に、配布物の文書にも書く。

## 影響

- 結果画面に 1 セクション増える
- `IClaudeTranscriptLocator`（Core の抽象）と実装（Analysis）が要る。
  実装はファイルの存在を調べるだけで、中身は読まない
- 段階 5 の README に、この節をそのまま載せられる

## 宿題

- `claude purge <パス>` で消せるかを確かめる。消せるなら「コマンドをコピー」も出す。
  ただし**作業フォルダは解析後に消えている**ので、消えたパスに対して purge が効くかは未確認
- 20 枚読ませたときの `.jsonl` の実サイズ（現在は 1 枚 104 KB からの外挿）

## 却下した案

| 案 | 却下の理由 |
|---|---|
| **アプリから `.jsonl` を消す** | 5.5 が「アプリからは削除しない」と明示している。加えて `projects` 配下は Claude Code 全体のデータで、**NutLens 以外のセッションを壊しうる** |
| README と初回セットアップにだけ書く | 初回セットアップは 1 回しか見ない。README は読まれないことがある。**解析のたびに増える**という性質が伝わらない |
| 何も言わない（5.5 は画像を消せと言っているだけ、と読む） | 消えていない複製があるのに「削除しました」とだけ出すのは、**検証の度合いを偽ること**に近い |
| エスケープ規則でパスを組み立てて表示する | 規則は推測。版が変わると**存在しないパスを「ここにあります」と出す**。嘘を表示するくらいなら「見つかりませんでした」のほうがよい |
| `--no-session-persistence` で履歴を残さない | `--resume` ができなくなり、F-27（再調査）が成立しない |
| セッションごとに作業ディレクトリ名を固定し、`projects` のフォルダを使い回す | 1 つの `.jsonl` に全解析が積み上がるだけで、量は減らない。むしろ 1 回分を選んで消せなくなる |
