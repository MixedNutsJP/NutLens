# ADR 索引

NutLens のアーキテクチャ決定記録（Architecture Decision Record）の一覧。

- 置き場：`docs/adr/NNNN-kebab-case-english.md`
- **1 ファイル 1 決定。** 決定を覆すときは既存を書き換えず、新しい番号で起こして旧側を「破棄」にする
- **ADR を書くのは維持者。** 寄稿者にお願いするのは「ここで決めたことを黙って変えない」ことだけ（[CONTRIBUTING.md](../../CONTRIBUTING.md)）
- **決定を足したら、この表に 1 行足すまでが 1 つの作業**

### 片付いた宿題

- 0004 ボックス平均縮小の端数処理 → テストで固定
- 0004 しきい値 5 が実際のフリップ動画で妥当か → **妥当でない。**
  ブラウザの窓ごと撮ると 14 場面が 6 枚に潰れる。原因は動かない部分が画面の大半を占めること
- 0004 保存後のフレームで測った距離が撮影時と同じか → 同じ（縮小によるずれは 1 以下）
- 0004 / 0015 ループ再生の繰り返しが何ビット離れるか → **3・11・11・19**（周期は実測 114.4 秒）。
  しきい値 12 で 3 つが落ち、1 つが残る。**残る 1 つを落とそうとすると別の場面も落ちる**ので 12 のまま
- 0015 枚数を増やしたときの「別の場面どうしの最小距離」 → 14 枚で 23、35 枚で 18、65 枚で 15
